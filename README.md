# 錢錢去哪兒

盤點資產、估算每月收支、對照想買的東西。從 e-diary 的財務功能獨立出來，給家人使用。

## 隱私

- 資料只存在使用者自己裝置的瀏覽器裡（IndexedDB），不會上傳，網站本身也沒有後端。
- 一人一本帳本。密碼是選填的：沒設密碼的帳本，用同一台電腦的人都能打開；設了密碼的帳本整份用 AES-GCM 加密，金鑰由密碼經 PBKDF2（60 萬次）推導。
- 忘記密碼就打不開，沒有後門。
- 備份檔是存在裝置上的那筆紀錄原樣匯出，所以有密碼的帳本，備份檔也是加密的。

## 安裝（Windows）

1. 用 Edge 或 Chrome 打開網址。
2. 按網址列右側的「安裝」圖示，或程式右上角的「安裝到桌面」。
3. 之後從桌面或開始功能表打開，沒網路也能用（抓匯率除外）。

資料跟著瀏覽器走：清除瀏覽資料時若勾選「Cookie 和網站資料」，帳本會被刪掉。所以請偶爾按「匯出備份」。

## 開發

不需要建置工具。

```powershell
python -m http.server 8010 --bind 127.0.0.1
```

- 程式：<http://127.0.0.1:8010/>
- 測試：<http://127.0.0.1:8010/tests/>（在瀏覽器裡跑，使用獨立的測試資料庫，不會動到帳本）

### 結構

- `js/core/`：計算與資料規則，不碰畫面，測試都在這一層。
- `js/store.js`：帳本的保存、加密、備份。
- `js/api.js`：畫面用的介面，函式名稱與回傳格式沿用 e-diary 的 API。
- `js/ui/`：畫面。`assets.js`、`cashflow.js`、`wishlist.js` 從 e-diary 移植。
- `sw.js`：離線快取（先上網拿最新版，連不上才用快取）。
